# gmail-digest — 每日邮件摘要助手 (work in progress)

A reusable, self-setup **daily email digest**: forward any mailbox (Outlook/QQ/163/Yahoo/iCloud/…)
into one Gmail, then get a filtered, LLM-summarized digest delivered on a schedule —
via **GitHub Actions + Anthropic API**, a **Claude Code routine**, or **local cron / Task Scheduler**.

Reads Gmail over the **Gmail API (HTTPS)**, so it runs anywhere (sandboxes that block IMAP/SMTP included).
Python **standard library only** — no `pip install`.

> ⚠️ **This repo is being built out automatically from [`PLAN.md`](PLAN.md).**
> Right now it contains the reusable core scripts from the original project plus the full
> implementation plan. The generalized project (setup wizard, API summarizer, CI workflow,
> bilingual docs) is being generated by a scheduled build.

## Current files
- `fetch_inbox.py` — read recent Gmail via the Gmail API → JSON
- `send_digest.py` — email the digest back via the Gmail API
- `gmail_common.py` — OAuth refresh-token + HTTPS helpers (stdlib)
- `gmail_oauth_setup.py` — one-time local OAuth helper → refresh token
- `ROUTINE.md` — customizable filtering/summary rules (also the routine prompt)
- `run_local.ps1` — local end-to-end runner
- `.env.example` — config template
- `PLAN.md` — full design + build plan

See `PLAN.md` for the complete design. Bilingual (English + 中文) setup docs are part of the planned build.
