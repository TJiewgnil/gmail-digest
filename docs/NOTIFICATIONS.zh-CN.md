# 手机通知

[English](NOTIFICATIONS.md) · **中文**

相关：[安装配置](SETUP.zh-CN.md) · [转发](FORWARDING.zh-CN.md)

目标：每日摘要一到，手机就提醒你 —— 而且**只**为摘要提醒，不为每封广告邮件响。

## 关键经验（先读这条）

> ⚠️ **在安卓上，设置“跳过收件箱（归档）”的过滤器拿不到实时推送通知。** Gmail 应用只对
> **留在收件箱**里的邮件可靠地推送。
>
> **正确做法是：把摘要留在收件箱**里，**同时打一个标签** —— 然后（可选）开启按标签的通知。
> **不要**归档它。

这是踩坑踩出来的：归档+打标签看着整洁，却悄悄让手机推送失效。把它留在收件箱，才能触发通知。

## 推荐配置

### 1. 把摘要发到一个专用地址

`send_digest.py` 默认发到你 `GMAIL_USER` 的 `<local>+digest@<domain>` 别名
（例如 `you+digest@gmail.com`）。Gmail 会把 `+后缀` 别名投递到同一个收件箱，于是你就有了一个
干净的过滤依据。（或者设置 `DIGEST_TO`。）

### 2. 建一个 Gmail 过滤器

*Gmail → 设置 → 过滤器和屏蔽的地址 → 新建过滤器。*

- **收件人（To）：** `you+digest@gmail.com`（或你的 `DIGEST_TO`），或**发件人（From）：**
  `you@gmail.com` 且主题包含 `Email Digest`。
- 点**创建过滤器**，然后勾选：
  - ✅ **应用标签：** 新建一个，例如 `Digest`。
  - ✅ （可选）**标为重要** / **加星标** / **始终标为重要**。
  - ❌ **不要**勾选“跳过收件箱（归档）”—— 留在收件箱才是手机推送能响的前提。

### 3. 打开 Gmail 应用通知

**安卓（Gmail 应用）：**
1. *设置 → （你的账号）→ 管理标签 → Digest → 标签通知 → 开启。*
2. *设置 → （你的账号）→ 通知 → 所有新邮件*（或至少允许 `Digest` 标签）。
3. 愿意的话，给 `Digest` 标签设一个独特的提示音/震动。

**iOS（Gmail 应用）：** *设置 → （账号）→ 通知 → 所有新邮件*，并在 iOS *设置 → 通知 → Gmail*
里开启 Gmail 的通知。（iOS 对归档问题没那么敏感，但把摘要留在收件箱仍是稳妥之选。）

### 4. 确保推送真的能送达

- **电池优化：** 把 Gmail 从激进省电里豁免（*安卓 设置 → 应用 → Gmail → 电池 → 不受限制*）。
  国产定制系统（小米/MIUI、三星、华为、一加、OPPO/vivo）是“通知延迟、只有打开应用才收到”的
  常见元凶。
- **账号同步：** 确认该账号的 Gmail 同步已开启（*设置 → （账号）→ 数据使用 → 同步 Gmail*）。
- **勿扰模式/日程：** 确认摘要到达的时间不落在勿扰时段内，或把 `Digest` 标签设为勿扰例外。

## 快速测试

运行 `python send_digest.py digest.md`（或手动触发一次 routine），确认：
1. 邮件出现在**收件箱**里并带有 `Digest` 标签；
2. 一两分钟内手机弹出通知。

若没有推送，依次复查：在收件箱（未归档）→ 标签通知已开 → 电池不受限 → 同步已开。
