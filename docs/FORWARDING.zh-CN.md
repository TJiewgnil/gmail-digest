# 把邮件转发进 Gmail

[English](FORWARDING.md) · **中文**

相关：[安装配置](SETUP.zh-CN.md) · [通知](NOTIFICATIONS.zh-CN.md)

## 原则

> **所有邮箱都转发汇入同一个 Gmail。工具只读 Gmail。**

这让工具保持简单、可移植：它只说 Gmail API（HTTPS），别的都不碰。你随时可以增减来源邮箱而
无需改代码 —— 只要在来源端开启（或停止）转发即可。

两种把邮件弄进 Gmail 的方式：

- **推（在来源端设转发规则）** —— 来源邮箱把每封新邮件自动转发到你的 Gmail。几乎实时，
  有此选项时首选。
- **拉（Gmail 通过 POP 收取）** —— Gmail 登录另一个账号，定期拉取新邮件
  （*Gmail → 设置 → 账号和导入 → 从其他账号检查邮件*）。当来源无法转发时用它
  （比如没有转发选项，或你不想动它的设置）。轮询较慢（几十分钟）。

> 提示：转发配好后，可凭每封 Gmail 邮件的 `from_addr` 判断它来自哪个来源 ——
> `ROUTINE.md` 就用它来做来源标注。

## Gmail → Gmail

*设置（齿轮）→ 查看所有设置 → 转发和 POP/IMAP → 添加转发地址。* 通过验证邮件确认后，选择
**将收到的邮件副本转发到** 你的主 Gmail。也可建过滤器只转发部分邮件。

## Outlook.com / Office 365

- **Outlook.com：** *设置 → 邮件 → 转发 → 启用转发 →* 填你的 Gmail → 保存。
  （想在 Outlook 里也留一份就勾选“保留副本”。）
- **Office 365（公司/学校）：** *网页版 Outlook → 设置 → 邮件 → 转发。* 若管理员禁用了转发，
  可用**收件箱规则**（*规则 → 添加新规则 → 重定向/转发到*），或找管理员开通，或退而用
  Gmail 的 POP 拉取。

## QQ 邮箱 / Foxmail

QQ 邮箱网页版 → *设置 → 收信规则 / 自动转发* → 把你的 Gmail 添加为转发目标并验证。可能需要先在
*设置 → 账户* 里开启相关服务。（Foxmail 与 QQ 邮箱共用后台，在 QQ 邮箱网页端配置即可。）

## 163 / 126（网易）

163/126 网页版 → *设置 → POP3/SMTP/IMAP* 以及 *设置 → 自动回复/转发*。开启自动转发到你的
Gmail 并验证。若改走 Gmail POP 拉取，网易通常要求用**客户端授权密码**而非登录密码。

## Yahoo 邮箱

部分账号的自动转发需要 Yahoo Mail Plus。若可用：*Settings → More Settings → Mailboxes →
（你的账号）→ Forwarding →* 添加你的 Gmail 并验证。否则用 **Gmail POP 拉取** 配合 Yahoo 的
**应用专用密码**（Yahoo *账户安全 → 生成应用密码*），因为 Yahoo 会拦截明文密码登录。

## iCloud 邮箱

*iCloud 邮件（网页）→ 设置（齿轮）→ 规则*，或 *偏好设置 → 通用 → 将我的邮件转发至* → 你的
Gmail。iCloud 原生支持转发，无需付费项目。

## 通用 IMAP/POP（学校、自定义域名、其他一切）

若来源不提供转发，就让 **Gmail 通过 POP 拉取**：

1. *Gmail → 设置 → 账号和导入 → 从其他账号检查邮件 → 添加邮件账号。*
2. 输入地址，再填 POP 服务器、端口、用户名和密码（若服务商要求，用**应用专用密码** /
   **授权码**）。
3. Gmail 会自动轮询并导入新邮件。

几乎任何开放 POP 的邮箱都适用，包括大多数学校和自定义域名邮箱。

## 转发之后

- 给每个来源各发一封测试邮件，确认都进了 Gmail。
- 如果某来源落到了 Gmail 的**垃圾邮件**或**促销**分类，建一个 Gmail 过滤器
  （*过滤类似邮件 → 永不将其发送至垃圾邮件 / 归类为主要*），好让摘要能看到它。
- 重跑 `python fetch_inbox.py --hours 24`，确认工具现在能看到所有来源的邮件
  （查看各条的 `from_addr`）。
